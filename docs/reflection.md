# Reflection — BJT DC Bias Web App

ENG29 2121 Lab 02 · ใบสะท้อนคิด (ฉบับร่าง)
วันที่: 2026-11-10

> หมายเหตุ: ไฟล์นี้เป็นฉบับร่าง ถ้อยคำส่วนที่เป็นความคิดเห็นส่วนตัวให้นักศึกษาแก้ไขให้ตรงกับประสบการณ์ของตนเองก่อนส่งงาน

## สิ่งที่ได้เรียนรู้จากการทำ Lab นี้

1. **แบ่งหน้าที่ชัดเจนช่วยให้ทดสอบง่าย** ผมแยกสมการวิศวกรรมไว้ใน `dc_bias.py` เพียงไฟล์เดียว โดยไม่ import Flask ทำให้ทดสอบสมการได้ทันทีด้วย unittest โดยไม่ต้องเปิดเว็บเซิร์ฟเวอร์ ถ้าเกิดปัญหาจะรู้ว่าตรงไหนผิดทันที

2. **หน่วยต้องชัดเจนตั้งแต่แรก** เลือกให้ผู้ใช้กรอกตัวต้านทานเป็น kΩ แล้ว backend คูณ 1000 ภายในโปรแกรม ตรงกับค่าตัวอย่างในเอกสาร Lab (100k, 22k, 2.2k, 1k) และลดโอกาสพิมพ์เลขศูนย์ผิด แต่ถ้าผู้ใช้เผลอกรอกเป็น Ω แทน kΩ ผลจะผิด 1000 เท่า — ต้องเขียน label `(kΩ)` ให้ชัดเจน

3. **การตรวจว่าไม่อยู่ในโหมด forward-active** Cutoff ตรวจได้จาก VTH ≤ VBE และคำนวณได้ถูกต้องทันที (กระแสเป็นศูนย์) ส่วน Saturation ต้องสมมติค่า VCE_sat เพิ่ม ซึ่งอยู่นอกขอบเขต Labนี้ ผมจึงคงตัวเลขจากสมการ Forward-Active ไว้แล้วแนบข้อความเตือนว่าใช้สมการนี้ไม่ได้ในโหมดอิ่มตัว

## ตัดสินใจอะไรไปบ้าง

| เรื่อง | ตัดสินใจ | เหตุผล |
|---|---|---|
| หน่วยตัวต้านทาน | กรอกเป็น kΩ | ตรงกับตัวอย่างในเอกสาร พิมพ์น้อย validation ง่าย |
| โครงสร้างผลลัพธ์ | ฟังก์ชันเดียวคืน `dict` | อธิบายได้ทุกบรรทัด ส่งเข้า Jinja template ได้เลย |
| เกณฑ์ Saturation | VCE ≤ 0.3 V | ค่ามาตรฐาน อธิบายง่าย |
| เกณฑ์ Cutoff | VTH ≤ VBE | ตรวจจากแรงดัน Thevenin โดยตรง |
| Validation | อยู่ใน `dc_bias.py` | ทดสอบสมการได้โดยไม่ต้องผ่าน HTTP |
| หน้าเว็บ | หน้าเดียว ไม่มี JavaScript | ตามขอบเขต Lab ลดจุดที่จะพัง |

## สิ่งที่ยังทำไม่ได้ / ข้อจำกัด

- **Saturation branch** ยังคงตัวเลข Forward-Active ไว้แล้วแจ้งเตือนเท่านั้น ถ้าอาจารย์ต้องการคำนวณ VCE_sat จริงต้องสมมติค่า VCE_sat เพิ่มเติม
- **ไม่มี JavaScript / กราฟ / AC analysis** ตามขอบเขต Lab 02 (เป็น DC bias เท่านั้น)
- **repo ยังเป็น Private** (หากยังไม่เปลี่ยนเป็น Public) อาจารย์อาจ clone ไม่ได้ ต้องเปิดเป็น Public หรือเชิญอาจารย์เป็น collaborator ก่อนส่งงาน
- ยังไม่ได้ทดลองกรณี edge case ทุกตัว เช่น ค่าที่ทำให้ VC ติดลบ (จะต้องตรวจเพิ่มว่าสมการยังใช้งานได้หรือไม่)
